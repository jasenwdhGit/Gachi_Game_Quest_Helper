# 手游日常助手 Gachi Game Quest Helper

基于 **Python 3 + PyQt5** 的桌面工具，用于记录与管理多款手游的
**日常 / 周常 / 双周常 / 月常 / 限时活动** 任务。界面全中文，数据保存在本地
`game_tasks.db`（SQLite），无需联网。窗口大小、分割条位置、全局刷新点等偏好
保存在 `config.ini`。

## 功能特性

### 游戏管理
- **多游戏管理**：添加游戏（上传图标图片 / 选择 EXE 自动提取图标）。
- **筛选栏右键即改**：在左侧「游戏筛选」列表右键某游戏，可
  - 修改名称、修改图标、重新加载 EXE
  - **一键添加日常** / **一键添加周常**（以「游戏名+类型」为任务名，按默认值直接入库，不弹窗）
  - 删除游戏（连同其下任务一起删除）
  - 「添加任务(自定义)」可打开对话框逐项设置
- **游戏管理窗口**：也可在「游戏管理」中改名、换图标、删除（刷新后保留选中项）。

### 任务周期（五种）
- **日常**：每 N 天，自定义刷新时间（默认 4:00）
- **周常**：指定星期几 + 刷新时间
- **双周常**：每 N 天（默认 14）+ 起始日期 + 刷新时间
- **月常**：每月几号 + 刷新时间
- **限时活动**：手动指定截止时间（0~28 小时制输入）

### 自动化与提醒
- **过期自动重置**：周期性任务一旦 `deadline ≤ 当前时间`，自动 `completed=False` 并将
  `deadline` 推进一个周期（无论是否已完成）；限时活动不重置。
- **全局刷新点**（默认 4:00，可改）：影响 28 小时制游戏时间显示；修改后重新计算所有周期性任务截止时间。
- **28 小时制游戏时间**：截止时间列以游戏时间展示（如刷新点 4:00 时 `8月17日 28:00`）。
- **通知提醒**：最多 10 条规则（每日/每周），每分钟检查，匹配时通过系统托盘气泡提醒。

### 界面与交互
- **可拖动三区布局**：游戏筛选 / 类型筛选 / 任务表 之间用分隔条，可自由拖拽调整大小
  （窗口大小与分隔条位置自动保存到 `config.ini`）。
- **剩余时间列**：在截止时间前显示人类可读的剩余时间（如「5天3小时」「已过期」）。
- **红色警告（按类型）**：
  - 日常：不警告
  - 周常：仅最后 3 天（或已过期）
  - 双周常 / 月常 / 限时活动：最后 7 天（或已过期）
  - 警告任务整行浅红显示。
- **左侧多选筛选**：游戏筛选 + 类型筛选，可组合；「全部游戏」与单个游戏勾选双向联动
  （全勾/无勾/部分勾）。
- **双击切换完成**：双击任务行（图标/游戏/任务/类型/剩余/截止任意列）即切换完成状态；
  双击「状态」「操作」列由按钮处理，不触发。
- **排序**：未完成在前（按剩余时间升序），已完成在末尾并灰显。
- **托盘驻留**：关闭可最小化到托盘（可记住选择）；托盘菜单提供「显示主窗口」「取消记住退出选择」「退出」。
- **导入/导出**：JSON 格式备份与恢复（导入前自动备份）。

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

> 需 Python 3.8+。依赖：`PyQt5`、`PyYAML`（如有）等，详见 `requirements.txt`。

## 目录结构

```
main.py        # 主窗口、三区可拖动布局、托盘、定时提醒、导入/导出、状态持久化
database.py    # DAO 层（SQLite + 自动更新 + 导入导出）
models.py      # 周期规则解析、deadline 推进、28 小时制换算、剩余时间、红警
dialogs.py     # 添加/管理游戏、添加/编辑任务、设置、提醒、关闭确认
_check_env.py  # 运行环境检测脚本
requirements.txt
README.md
config.ini     # 用户偏好（窗口几何、分割条、刷新点、关闭行为）
game_tasks.db  # 本地数据库
```

## 关键规则说明

- **period_rule 格式**：`1d@04:00`、`7d@0@04:00`、`14d@2026-08-08@04:00`、`1m@01@04:00`。
- **28 小时制输入**：截止时间小时可选 0~28；`H≤23` → 当日 `H:MM`，`H≥24` → 次日 `(H-24):MM`。
- **游戏时间显示**：以全局刷新点小时 `R` 为界，`hour<R` 显示前一日 `(hour+24)` 点；
  `hour==R` 显示前一日 `(R+24)` 点；`hour>R` 显示当日 `hour` 点。
- **用户偏好**：全局刷新点、关闭行为记忆、窗口几何、分割条位置存于 `config.ini`。

## 快速上手

1. 运行 `python main.py`，右上角「设置」设置全局刷新点（默认 4:00）。
2. 左侧「游戏筛选」右键 →「添加任务(自定义)」或「一键添加日常/周常」录入任务。
3. 拖动分隔条调整三区大小；关闭后布局自动恢复。
4. 双击任务行切换完成；任务临近截止时整行浅红提醒。
5. 托盘菜单「取消记住退出选择」可重置关闭行为；「导出」做 JSON 备份。
