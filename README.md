# 手游任务助手 Gacha Game Quest Helper

一个面向多款手游的**日常 / 周常 / 双周常 / 月常 / 限时活动**任务管理桌面应用，采用 Fluent Design 风格 UI，支持任务周期自动重置、托盘提醒、主题切换与 JSON 导入导出。

- **UI 框架**：PyQt5 + [PyQt-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)
- **存储**：本地 SQLite（无需联网）
- **平台**：Windows（图标提取依赖 pywin32）

## 功能特性

- **多游戏管理**：为每个游戏指定 EXE 程序或图标，自动提取程序图标展示在任务卡片上
- **五种任务类型**：
  - 日常、周常、双周常、月常 —— 支持周期自动重置（过期后自动推进下一次截止）
  - 限时活动 —— 截止时间由用户直接指定
- **28 小时制游戏时间**：适配多数手游以凌晨 4 点作为每日刷新点的设定，可自定义全局刷新时刻
- **任务卡片**：游戏图标、任务名、类型标签（按类型着色）、截止/剩余时间、完成状态一键切换；开启提醒的任务显示铃铛标识
- **筛选面板**：按游戏、按任务类型勾选过滤，支持折叠
- **到期提醒**：自定义提醒规则（每日/每周/每月、按游戏/任务类型过滤，最多 10 条），到点通过系统托盘气泡提醒，按周期去重
- **红色警告**：周常最后 3 天、其他类型最后 7 天进入红色紧急提示
- **主题切换**：浅色 / 深色，任务卡片与界面配色自适应
- **数据导入导出**：JSON 格式，导出时自动备份旧数据

## 目录结构

```
.
├── main.py            # 主程序（任务、提醒、设置、关于界面 + 托盘 + 定时器）
├── main.pyw           # 无控制台入口（pythonw 运行，避免托盘程序闪现控制台）
├── models.py          # 业务规则：周期解析、截止计算、28 小时制时间、红色警告
├── database.py        # 数据访问层：SQLite DAO、过期自动重置、导入导出
├── ui_dialogs.py      # 对话框层：游戏/任务/关闭确认，exe 图标提取
├── requirements.txt   # 依赖清单
└── userdata/          # 运行时数据（自动生成，不入库）
    ├── game_tasks.db       # SQLite 数据库
    ├── config.ini          # 窗口布局 / 主题 / 刷新时刻等配置
    └── game_tasks.json     # 导入导出文件（可选）
```

## 安装

要求 Python 3.8+。

```bash
# 1. 安装依赖
pip install -r requirements.txt
```

> 依赖说明：
> - `PyQt-Fluent-Widgets`：Fluent UI 控件库
> - `PyQt5`：Qt 绑定
> - `pywin32`：用于从 .exe 提取程序图标（Windows）
> - `Pillow`：图标位图转换

## 运行

```bash
# 带控制台运行（便于查看报错）
python main.py

# 无控制台运行（托盘常驻，推荐）
pythonw main.pyw
```

也可以使用 PyInstaller 打包为 .exe（建议 `--noconsole`），打包后数据目录自动定位到程序同目录。

## 数据目录

默认数据存放在**程序同目录下的 `userdata` 文件夹**，可通过环境变量自定义：

```bash
# Windows
set GAME_TASK_DATA_DIR=D:\my_game_data
```

## 使用说明

1. **添加游戏**：进入「游戏管理」→「添加游戏」，填写名称并选择 EXE 程序或图标文件（可自动提取程序图标）。
2. **添加任务**：在任务页点击「添加任务」，选择游戏、任务类型，按类型配置周期（如周常选星期几 + 刷新时刻），或为限时活动指定截止时间。
3. **完成任务**：点击卡片上的状态标签或双击卡片，在「未完成 / 已完成」间切换。
4. **配置提醒**：进入「提醒」页面，选择 每日/每周/每月 + 时间 + 游戏/任务类型筛选，添加提醒规则（最多 10 条），到点托盘气泡提醒。
5. **筛选任务**：左侧面板勾选游戏与任务类型进行过滤。
6. **主题与设置**：进入「设置」调整全局刷新时刻、关闭行为、主题，并可导出/导入 JSON 数据。
